Reviewed on 2026-10-15 using the official product pages. Cards use list prices,
not the promotional amounts in the older raw crawl. Range retains its stated
NEDC/WLTP standard. Unknown values are not copied from another version.

VF7's hero summary combines the Plus FWD range with the AWD maximum power.
The detailed specification table separates them: Plus FWD has 500.5 km NEDC
and 150 kW; Plus AWD has 469 km NEDC and 260 kW. The Plus FWD list price is
830 million VND. A separate AWD list price has not been verified, so its card
displays `Chưa có giá xác thực`. The official Plus illustration is shared by
the two Plus configurations.

A single-model overview shows all supported versions. An explicit version
shows only that version. Cross-model comparisons use Eco by default and honor
versions attached to each model. Unsupported versions (for example VF5 Plus)
do not silently fall back to a different card.
